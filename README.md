# NEXORA

**AI × Finance × Blockchain**

NEXORA is a security-first financial technology platform in development. The first product is **NEXORA AI Terminal**, a modular command center for market data, portfolio intelligence, risk analysis, wallets and developer infrastructure.

## Current status

The repository contains the initial Next.js application foundation, public landing page, AI Terminal demo interface, environment template and styling system.

> **DEMO DATA:** Live market providers, authentication, database persistence, wallet connectivity, AI execution and blockchain deployment are not enabled yet. No simulated values are presented as real financial data.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## Principles

- Utility before hype
- Security before speed
- Real data before claims
- Permissioned AI before autonomous financial execution
- Testnet before mainnet
- No private keys or seed phrases requested
